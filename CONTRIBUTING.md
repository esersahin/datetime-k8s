# DateTime Kubernetes Projesine Katkı

İlginiz için teşekkürler! Katkıda bulunmak için:

## Nasıl Katkıda Bulunulur

1. Repository'yi fork edin
2. Feature branch'inizi oluşturun (`git checkout -b feature/[FeatureName]`)
3. Değişikliklerinizi commit edin (`git commit -m '[FeatureName] eklendi'`)
4. Branch'inizi push edin (`git push origin feature/[FeatureName]`)
5. Pull Request açın

## Davranış Kuralları

Tüm etkileşimlerde saygılı ve yapıcı olun.
